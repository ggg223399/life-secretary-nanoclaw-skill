## 设计原理

> 这一节解释计划背后的"为什么"。如果你只想看"怎么做"，可以跳到下一节。

### 为什么选上下肢分化，不选推拉腿？

|            | 推拉腿（PPL） | 上下肢（U/L） | 全身     |
| ---------- | ------------- | ------------- | -------- |
| 每周天数   | **6 天**      | **4 天**      | 3 天     |
| 每肌群频率 | 2 次/周       | 2 次/周       | 3 次/周  |
| 每次时长   | 45-60min      | ~60min        | 60-75min |
| 适合阶段   | 中高级        | **新手-中级** | 纯新手   |

你的情况：每周 4 天、60 分钟、运动基础低。

- **PPL 需要 6 天**才能让每块肌肉练到 2 次/周。你只有 4 天，PPL 一轮半跑不完，频率不够。
- **全身训练（3 天）**对纯零基础更好，但你偶尔有器械经验，且目标 4 天/周，全身每次塞太多动作容易超时。
- **上下肢 4 天**刚好：每肌群 2 次/周的频率，每次 4 个动作 60 分钟内搞定，还能在上肢日后加间歇不影响腿恢复。

推拉放同一天不是问题——推（胸/肩/三头）和拉（背/二头）是**拮抗肌群**，互不干扰。反而有研究表明拮抗超级组能轻微提升力量表现。

### 为什么 RIR 2-4 而不是练到力竭？

**RIR（Reps In Reserve）= 还能再做几个就停。** RIR 2 = 还剩 2 个就放下。

- 新手的 RPE 感知不准（以为 RPE 7 其实已经 RPE 9），RIR 更直觉："还能再做 2 个吗？能→继续，不能→停"
- 力竭训练对增肌的边际收益很小（~5%），但疲劳、受伤风险和恢复需求大幅增加
- RIR 2-4 已经覆盖了有效增肌刺激区间（[研究共识](https://pubmed.ncbi.nlm.nih.gov/34735411/)：距力竭 0-4 次都能有效增肌）
- 留余力 = 技术不变形 = 受伤风险低 = 能持续训练 = 长期收益更大

### 为什么减脂用温和赤字（10-15%）？

你的目标是**减脂同时增肌**（身体重组），不是单纯减重。

- **大赤字（>20%）**：掉秤快，但新手肌肉也跟着掉，训练状态差，容易放弃
- **温和赤字（10-15%）**：新手有"新手红利"——即使在轻度赤字下也能同时增肌减脂，前提是蛋白质吃够
- 你的赤字 ≈ 220-320kcal/天，大约每周减 0.2-0.3kg，12 周目标减 2-4kg。不激进但可持续

### 为什么蛋白质是最高优先？

减脂期的核心矛盾：**热量不够，身体要分解东西供能——分解脂肪还是肌肉？**

- 蛋白质充足（1.6-2.0g/kg）→ 信号告诉身体"肌肉还在用，别拆" → 优先分解脂肪
- 蛋白质不够 → 身体同时分解脂肪和肌肉 → 体重掉了但体脂率没变，体型没改善
- 减脂期蛋白质需求比增肌期**更高**，不是更低

你的最低线：**每天 120g**（约 4 掌肉）。

### 为什么 Zone2 占体能的 80%？

Zone2 = 能完整说话、鼻呼吸的强度（心率 60-70% HRmax）。

- **80/20 法则**（挪威模型）：精英耐力运动员 80% 低强度 + 20% 高强度，业余爱好者更应如此
- Zone2 提升线粒体密度和脂肪氧化能力——这正是你减脂需要的代谢基础
- 高强度间歇（HIIT）看似更"高效"，但对新手：恢复慢、影响力量训练、受伤风险高、容易过度训练
- Zone2 不产生额外疲劳，不影响力量日恢复——可以叠加在力量训练后

### 为什么分阶段而不是一步到位？

| 阶段       | 核心目标           | 不急着做                 |
| ---------- | ------------------ | ------------------------ |
| 第 1-2 周  | 建立出勤习惯       | 不追求完美动作/营养/有氧 |
| 第 3-4 周  | 过渡到完整训练结构 | 不加间歇                 |
| 第 5-8 周  | 全面运行           | 不急着加重量             |
| 第 9-12 周 | 巩固 + 评估        | 不换计划                 |

- 一次性改变太多（训练 + 饮食 + 作息）→ 认知和意志力超载 → 2-3 周后全面崩盘
- 每 2 周只加一个新变量 → 每个习惯有时间固化 → 12 周后全部变成"默认行为"
- 行为科学的"最小可行习惯"原则：**先做到"做了"，再追求"做好"**

- **热身 8-12min**：轻有氧 3-5min → 动态活动 3-5min → 主项热身组 2-4 组递增

### 进阶与回退规则

**进阶（双进阶法）**：
- 所有工作组做到次数范围上限 + 最后一组 RPE ≤ 8 + 动作稳定 → 下次加重 2.5-5%
- 部分组达标 → 先补齐再加重

**回退**：
- 热身时同重量 RPE 异常高 → 当天减重 5-10% 或少做 1 组
- 出现疼痛（非酸胀）→ 换同模式低痛替代，RPE 控在 6-7

**停滞处理**：
- 连续 2 次卡住 → 目标改为加 1-2 次总次数
- 仍不动 → 减重 10% 做 1 周，下周再回原重量

## 二、体能教方案

### 每周体能配比

| 类型       | 时间                              | 占比      |
| ---------- | --------------------------------- | --------- |
| Zone2 有氧 | 120-150min/周                     | 80-90%    |
| 间歇       | 20-30min × 1次/周                 | 10-20%    |
| 步数       | 8,000-12,000步/天                 | 日常 NEAT |
| 灵活性     | 训练日 10-15min / 休息日 20-30min | 恢复      |

### 强度定义

| 类型     | 心率         | RPE     | 体感               |
| -------- | ------------ | ------- | ------------------ |
| Zone2    | 60-70% HRmax | 3-4     | 能完整说话、鼻呼吸 |
| 间歇硬段 | 85-92% HRmax | 7.5-8.5 | 明显急促但动作不散 |
| 恢复段   | -            | 1-2     | 非常轻松           |

### 干扰最小化规则

- **顺序**：力量 → 有氧（不要反过来）
- **间隔**：能分开 6-8 小时最佳；不能就把 Zone2 放力量后
- **间歇位置**：放在上肢日后，距离下肢日 ≥ 24 小时
- **下肢日**：力量后只做 10-15min 超轻松走/骑，不做长有氧

### 与力量日的组合

| 天        | 力量 | 体能                                  |
| --------- | ---- | ------------------------------------- |
| D1 上肢 A | 正常 | **力量后间歇 20-30min** + 拉伸 5-8min |
| D2 下肢 A | 正常 | 力量后 10-15min 轻松走 + 灵活性 10min |
| D3        | 休息 | 步数达标 + 灵活性 20-30min            |
| D4 上肢 B | 正常 | 力量后 Zone2 35-50min + 灵活性 10min  |
| D5 下肢 B | 正常 | 力量后 Zone2 20-30min + 灵活性 10min  |
| D6-7      | 休息 | 步数达标 + 灵活性 20-30min            |

### 间歇方案（二选一）

**方案 1（新手友好）**：热身 8-10min → 6 组（1min 硬 RPE8 + 2min 轻松）→ 冷却 5-8min

**方案 2（偏耐力）**：热身 8-10min → 4 组（3min 中硬 RPE7-8 + 3min 轻松）→ 冷却 5-8min

### 进阶与边界

- 前 2 周稳定执行 → Zone2 每次 +5min 或每周总量 +10-15min
- 出现力量退步/持续疲劳 >3 天/睡眠变差 → 间歇减半或暂停 1 周

## 三、营养师方案

### 热量策略（基于 73kg）

| 步骤     | 公式                   | 你的数值       |
| -------- | ---------------------- | -------------- |
| BMR      | 体重×22                | 1606           |
| TDEE     | BMR × 1.35（低活动量） | **~2170**      |
| 目标摄入 | TDEE × 0.85-0.90       | **~1850-1950** |

> 赤字控制在 10-15%，不超过 20%。你当前微超重，15% 赤字（~1850）是合理起点。
> 随着训练量增加（第 3-4 周起），TDEE 会上升，届时活动系数可调到 1.4-1.5。

### 宏量营养素（基于 73kg）

| 营养素 | 目标        | 你的量       | 优先级                     |
| ------ | ----------- | ------------ | -------------------------- |
| 蛋白质 | 1.6-2.0g/kg | **117-146g** | 最高（减脂期保肌肉的关键） |
| 脂肪   | 0.8-1.0g/kg | 58-73g       | 不可低于（激素健康）       |
| 碳水   | 剩余热量    | 170-220g     | 训练日偏高，休息日偏低     |

> **减脂期蛋白质特别重要**：你在赤字状态下训练，蛋白质吃够才能减脂不掉肌肉。
> 简单记：**每天至少 120g 蛋白质**，4 掌肉就够。

### 手掌估算法（长期方案）

| 手势                    | 对应   | 约等于 |
| ----------------------- | ------ | ------ |
| 一个手掌大小的肉        | 蛋白质 | 25-30g |
| 一个拳头大小的主食      | 碳水   | 40-50g |
| 一个拇指大小的油脂/坚果 | 脂肪   | 10-15g |
| 两手捧满的蔬菜          | 随意吃 | 不用算 |

**每餐目标**：1 掌肉 + 1 拳主食 + 1 拇指油脂 + 随意蔬菜

### 训练前后营养

| 时机            | 内容                          | 原则                   |
| --------------- | ----------------------------- | ---------------------- |
| 训练前 60-90min | 香蕉+面包（碳水为主、易消化） | 不空腹、不高脂         |
| 训练中          | 纯水 400-600ml，少量多次      | 75min 内不需要运动饮料 |
| 训练后 30-60min | 肉+主食（完整正餐）           | 蛋白+碳水启动修复      |

### 监测与调整（四象限决策）

| 场景       | 体重 | 腰围 | 力量 | 对策                                |
| ---------- | ---- | ---- | ---- | ----------------------------------- |
| A 完美     | 缓降 | 缓降 | 在涨 | 不改，至少再观察 2 周               |
| B 最佳重组 | 不变 | 在降 | 在涨 | 不要恐慌，保持不动                  |
| C 平台期   | 不变 | 不变 | 停滞 | 先查蛋白→再查睡眠→最后减碳水 30-50g |
| D 赤字过大 | 在降 | -    | 在掉 | 增碳水 30-50g，检查蛋白和睡眠       |

**调整节奏**：最短观察 2 周，单次调整 ±150-200kcal，每次只改一个变量。

### 补剂立场

| 补剂             | 建议                   |
| ---------------- | ---------------------- |
| 蛋白粉           | 可选，食物凑不够时使用 |
| 肌酸（一水肌酸） | 可考虑，5g/天          |
| 维生素 D         | 冬季/少晒太阳可补      |
| BCAA/氮泵/左旋   | 不推荐，省钱           |

### 依从性策略

- **80/20 法则**：80% 遵循计划，20% 灵活
- **周末灵活餐**：每周 1-2 顿不计较
- **备餐**：周日备 3-4 天蛋白质（煮鸡胸、卤牛腱）
- **前 2 周用 APP 记录**熟悉份量感，之后凭手掌估算

## 四、质疑官审查

### 关键风险点

| #   | 风险                                             | 依据                                  |
| --- | ------------------------------------------------ | ------------------------------------- |
| 1   | 单次 4-6 个复合动作 × 4 天，技术不稳时周总量过高 | 新手神经/结缔组织适应慢               |
| 2   | RPE 6-8 对新手不友好                             | 新手往往高估余力，实际更接近 RPE 8-10 |
| 3   | 深蹲/硬拉/卧推/推举全上                          | 技术+负荷+疲劳三重叠加                |
| 4   | 力量后接 25-50min Zone2                          | 并行训练干扰，下肢日后长有氧影响恢复  |
| 5   | 加重 2.5-5% 对上肢偏激进                         | 上肢小肌群用 +1kg 更稳                |
| 6   | 缺少减量周                                       | 连续 4-6 周无减量容易累积疲劳         |

### 具体改法

1. **动作压到 3-4 个主项 + 1 核心**，每主项 **2-3 组**（不是 3-5 组）
2. **用 RIR 替代 RPE**：所有工作组 **RIR 2-4**（留 2-4 次余力）
3. **动作降门槛**：
   - 深蹲 → 高杯深蹲/腿举
   - 硬拉 → 罗马尼亚硬拉（轻）+ 臀桥
   - 卧推 → 哑铃卧推/俯卧撑
   - 推举 → 哑铃推举（坐姿）
   - 杠铃划船 → 器械划船/胸托划船
4. **Zone2 从 20-30min 起步**，优先放非下肢日
5. **递进加"质量门槛"**：动作一致性达标才加重；上肢 +1kg
6. **每 4-6 周减量 1 周**：组数减 30-50%，强度不变

### 红旗信号（出现立即降量）

- 关节刺痛/麻、下背不适加重
- DOMS 影响日常 > 72 小时
- 睡眠变差、静息心率持续上升
- 训练后累到恶心/头晕、食欲明显下降

## 综合建议

### 共识点（5 位专家一致认同）

1. **新手不需要复杂分化**：全身/上下肢交替优于推拉腿
2. **强度控制 > 训练量**：留余力（RIR 2-4），不力竭
3. **习惯 > 完美**：前 4 周只追踪出勤率
4. **渐进统一**：先做满次数 → 再加重量
5. **家/馆双版本**：每个动作给两套实现方式

### 二、动作图鉴

#### 上肢动作（D1/D4）

**哑铃卧推**
躺在长凳上，双手各拿一个哑铃在胸口上方，往上推、放下、再推。主要练**胸肌**（胸口那两大块肉）。
⚠️ 常见错误：手臂推得太往头的方向，应该往脚的方向推一点，大概 45 度角。

**器械胸推**
坐在器械上，双手握把手往前推。练的也是**胸肌**，比哑铃卧推更安全（不会掉到脸上），适合新手。
⚠️ 常见错误：肩膀耸起来了，应该沉肩、肩胛骨收紧贴在椅背上。

**俯卧撑 / 脚抬高俯卧撑**
双手撑地、身体一条直线、弯手肘让胸口接近地面、再撑起来。练**胸肌+手臂后侧+核心**。脚抬高版是把脚放椅子上，难度更大、更练胸肌上部。
⚠️ 常见错误：屁股翘起来或者塌腰，应该全程收紧肚子保持身体一条直线。

**上斜哑铃卧推**
躺在斜向上 30-45 度的凳子上做卧推。更侧重练**胸肌上部**。
⚠️ 常见错误：凳子角度太陡（超过 45 度）就变成肩推了，保持 30-40 度。

**坐姿划船 / 胸托划船**
坐着拉绳索，手肘往后拉、肩胛骨夹紧、再放回。练**背部**（肩胛骨之间那一大片肉）。胸托版是趴在斜板上拉，更孤立地练背。
⚠️ 常见错误：用手臂发力拉，应该想象用肘部带动、肩胛骨往中间夹。

**单臂哑铃划船 / 弹力带划船**
单臂版：一只手撑凳子、一只腿跪凳子上，另一只手拿哑铃往上拉。弹力带版：站着或坐着拉弹力带。都练**背部**。
⚠️ 常见错误：全程手臂伸直拉，应该手肘弯曲、往后拉肘而不是拉手。

**高位下拉 / 弹力带下拉**
坐着往下拉头顶上方的横杆（或固定在高处的弹力带）。练**背阔肌**（让背变宽的那块肉）。
⚠️ 常见错误：身体后仰太多借力，应该身体稍微后倾 15 度左右、用背发力拉。

**单臂绳索划船**
站着单手拉绳索，身体可以稍微旋转。比双臂划船更能练到**核心稳定**和单侧背部。
⚠️ 常见错误：拉的路线不对，应该拉向肚脐位置、不是胸口。

**哑铃肩推 / 弹力带推举**
坐着或站着，双手各拿哑铃（或踩弹力带）从肩膀位置往头顶推。练**肩膀**（肩膀上面那一坨）。
⚠️ 常见错误：推的时候塌腰，应该收紧核心、骨盆微微后倾。

**哑铃侧平举 / 弹力带侧平举**
站着，双手各拿哑铃（或站在弹力带上）从身体两侧往外举到肩膀高度。练**肩膀两侧的肉**，让肩变宽。
⚠️ 常见错误：手臂举太高（超过肩膀）或耸肩，想象倒水的动作、小拇指侧稍微高一点。

**弯举**
站着或坐着，手臂弯曲把哑铃举向肩膀。练**手臂前侧**（二头肌，展示肌肉时鼓起来那块）。
⚠️ 常见错误：大臂晃动借力，应该大臂固定在身体两侧、只动小臂。

**下压（三头）**
站着往下压绳索或弹力带。练**手臂后侧**（三头肌，拜拜肉的位置）。
⚠️ 常见错误：手肘位置乱动，应该手肘固定在身体两侧、只动小臂。

#### 下肢动作（D2/D5）

**高脚杯深蹲**
双手抱着哑铃在胸前，往下蹲、站起来。练**大腿前侧+屁股**。
⚠️ 常见错误：膝盖内扣，应该膝盖和脚尖同方向、想象往外推开地面。

**腿举**
躺在器械上，双脚蹬板子往外推。练**大腿+屁股**，比深蹲对腰背压力小。
⚠️ 常见错误：膝盖锁死到底，应该保持微微弯曲、不要完全伸直。

**哑铃罗马尼亚硬拉（RDL）**
站着拿哑铃，屁股往后推、上半身前倾、哑铃沿着腿往下滑到小腿中间，再站起来。练**大腿后侧+屁股+下背**。
⚠️ 常见错误：弯腰而不是推屁股，应该想象屁股碰后面的墙、背全程挺直。

**保加利亚分腿蹲**
后脚搭在凳子或沙发上，前脚往下蹲。单腿深蹲的变种，练**大腿+屁股+平衡**。
⚠️ 常见错误：重心在后腿，应该 90% 重量在前腿、后腿只是辅助平衡。

**腿弯举 / 滑垫腿弯举**
器械版：趴着把小腿往屁股方向勾。滑垫版：仰卧、脚踩滑垫、屁股抬起来同时弯腿。练**大腿后侧**。
⚠️ 常见错误：器械版屁股抬起来借力；滑垫版屁股掉下来。都应该保持稳定姿势。

**臀推（Hip Thrust）**
上背靠在凳子上，屁股悬空，髋部往上顶、屁股夹紧。最直接练**臀部**的动作。
⚠️ 常见错误：腰往上拱，应该想象骨盆后倾、用屁股而不是腰发力。

**单腿臀桥**
仰卧，一只脚踩地、另一只腿伸直或抬起，屁股往上顶。练**臀部+大腿后侧**。
⚠️ 常见错误：身体歪向一边，应该保持骨盆水平、两侧髋骨一样高。

**反向弓步**
站着，一条腿往后撤一大步、下蹲、再回来。练**大腿+屁股**，比前弓步对膝盖友好。
⚠️ 常见错误：上半身前倾太多，应该保持躯干直立、像电梯一样垂直上下。

**弹力带早安式**
弹力带踩脚下绕过脖子，屁股往后推、上半身前倾。练**下背+屁股+大腿后侧**。
⚠️ 常见错误：弯腰驼背，应该背挺直、想象脊柱是一根棍子。

**站姿提踵 / 台阶提踵**
站着脚后跟往上抬、垫脚尖。台阶版是站在台阶边缘、脚后跟悬空，幅度更大。练**小腿**。
⚠️ 常见错误：晃来晃去，应该核心收紧、只动脚踝。

#### 核心动作

**平板支撑**
俯卧，手肘撑地、身体一条直线。练**核心**（肚子周围一圈肌肉）的耐力。
⚠️ 常见错误：塌腰或撅屁股，想象肚子往脊柱方向收、屁股微微夹紧。

**死虫（Dead Bug）**
仰卧，手臂往上伸、膝盖弯曲抬起，对侧手脚交替伸直、收回。练**核心控制**+手脚协调。
⚠️ 常见错误：下背离地，应该下背全程压紧地面、想象后腰吸在地上。

**侧桥**
侧卧，一侧手肘撑地、身体一条直线、髋部抬起。练**侧腹**（腰两侧的肉）。
⚠️ 常见错误：髋部往下掉，想象身体是一块板、全程绷紧。

**反向卷腹**
仰卧，抬腿、卷起下腹让膝盖往胸口移动。练**下腹**（肚脐以下）。
⚠️ 常见错误：用惯性甩腿，应该慢慢控制、想象把骨盆往肋骨方向卷。

**鸟狗式（Bird Dog）**
四肢撑地，对侧手脚同时伸直（像一只指着猎物的狗）。练**核心稳定+背部+平衡**。
⚠️ 常见错误：身体晃，应该动作慢、想象头顶和伸出的脚跟往两边拉长。

#### 体能动作

**农夫走**
双手各拎一个重物（哑铃/水桶）走路。练**全身力量+握力+核心**。
⚠️ 常见错误：耸肩或身体歪，应该肩膀下沉、躯干直立、步伐稳定。

**开合跳**
站着，跳起来的同时双脚外展、双手头顶击掌，跳回并拢。经典**有氧动作**。
⚠️ 常见错误：全脚掌重重落地，应该前脚掌先着地、轻盈点像猫。

**桌子反向划船**
钻到桌子下面，双手抓桌子边缘、脚踩地、身体斜向上拉。家庭版引体向上，练**背+手臂**。
⚠️ 常见错误：身体松垮，应该全程绷紧、屁股别掉下来、保持身体一条直线。
